# 🍽️ Restaurant Menu & Billing System

A beginner-friendly Python project for managing a restaurant menu and calculating customer bills.

## 📌 Features

- Display restaurant menu
- Select food items
- Enter quantity
- Calculate total bill
- Simple and easy-to-use Python program

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Download or clone this repository.
2. Open the Python file.
3. Run the program using Python.
